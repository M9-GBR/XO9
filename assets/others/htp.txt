XO9 is a 2 player turn based strategy board game. It is played on 9 "Squares" arranged in a 3x3 grid.
Each of these Squares has a set of 9 squares in them called "Cells" also arranged in a 3x3 grid. You occupy Cells
to capture Squares to eventually win the game.
//
Each player has to play as either X or O. X always plays first. The player which has their turn to play must do so in an
Open or Current square. This Current square is known by the "Square Slider" being around it. The Square Slider is a stroked
square that is coloured red (when it's X's turn) or blue (when its's O's turn) that slides from Square to Square to show which Square
is currently open. Square 5 (S5) is always the Open Square at the starting of each game which means when the game starts X must occupy
a cell in Square 5. Only empty cells can be occupied. To occupy a cell simply click/tap on it or if you prefer keyboard controls
use the numeric keys to specify the cell you want to occupy.
//
After a cell has been occupied, the Current Square changes. Say X plays on Square 5 Cell 3 (S5C3), then the next Open Square will be
Square 3 (S3). Simply if a player plays on Square m Cell n, the Current Square changes from Square m to Square n. The Square Slider will
move to that Square and change colour depending on whether the next player is X (red) or O (blue).
//
A square is captured just like in a game of tic-tac-toe. If 3 Cells in a row, horizontally, vertically or diagonally are occupied
by a specific character (X or O), the Square containing that pattern is captured by the character that made the pattern.
Empty Cells in a captured Square can no longer be occupied. Should the Open Square eventually be a Sqaure that has been captured
then the board becomes "Open" and the next player can occupy any Cell in any Square that has not been captured. 
//
If every Cell in a Square becomes occupied and no capture happens (similar to a draw in tic-tac-toe) then a "Draw Cross" happens.
When a Draw Cross occurs, the Square that initiated the event with the Squares at the top, bottom, left and right of it becomes completely
cleared, if it was captured it becomes uncaptured and every Cell in them becomes empty.
//
An XO9 game is primarily won in 2 ways - By Main and By Count. To win By Main, the player has to capture 3 Squares in a row, vertically,
horizontally or diagonally. A win By Count happens when every single Square in the board has been captured but none of the captures were done
in a way to initiate a Win By Main, when this happens the player that captured the most Squares has won the game. A game can be drawn if
9 Draw Crosses happen.
